# SmartNest Dashboard

داشبورد لزباين Home Assistant: مخطط البيت عليه الأجهزة، وصفحات بتنبني من عناصر، وستايل Apple بهوية SmartNest.

> **EN:** A Home Assistant dashboard panel with an interactive floor plan, Apple-style controls, Arabic/English/Hebrew (RTL), a doorbell popup and a PIN-protected kiosk lock. Install through HACS as a custom repository (category: Integration), then add the "SmartNest Dashboard" integration.

## التفعيل (لكل بيت كود)

الداشبورد ما بيشتغل بدون **كود تفعيل** مربوط ببيت واحد. أنت لحالك بتقدر تطلّع الكود.

1. عند الزبون، افتح SmartNest. بيطلعلك **رقم التركيب**، انسخه.
2. على جهازك:
   ```bash
   node scripts/license.mjs <رقم-التركيب> "بيت أبو محمد"
   ```
3. حط الكود اللي طلع (بيبلّش بـ `SN1.`) بشاشة التفعيل، واضغط **فعّل**. لازم تكون داخل بحساب أدمن.

- **المفتاح السري** موجود بـ `~/.smartnest/license-private.pem` على جهازك بس، ومش بالـ repo. **اعمله backup** (مثلاً بمدير كلمات السر): إذا ضاع، ما بتقدر تطلّع أكواد جديدة، وإذا حدا أخذه، بيقدر يطلّع أكواد.
- الكود **لبيت واحد بس**. إذا حدا نسخه لبيت ثاني، ما بيزبط.
- ما في سيرفر ولا إنترنت: التحقق بيصير جوا HA الزبون.
- **حدود الحماية:** الكود ظاهر بالـ repo العام، فمبرمج شاطر بيقدر يعدّل الملفات ويشيل الفحص. هاد بيمنع الاستعمال العادي، مش الاختراق المقصود.

### الباقات والاشتراكات
```bash
node scripts/license.mjs <رقم> "الاسم" --plan basic           # أساسي
node scripts/license.mjs <رقم> "الاسم" --plan pro --days 365  # Pro لسنة
node scripts/license.mjs <رقم> "الاسم" --trial                # تجربة Premium لـ 14 يوم
node scripts/license.mjs <رقم> "الاسم" --reseller "شركة نور"   # كود لموزّع
```
بدون `--plan` بتطلع Premium، وبدون `--days` ما بتنتهي. قبل الانتهاء بأسبوعين الأدمن بيشوف تذكير. ولما يخلص الاشتراك، بترجع شاشة التفعيل لحد ما تحط كود جديد.

| الباقة | شو بتفتح |
|---|---|
| **أساسي** | المخطط، الأجهزة، الكاميرات، الساعة، العناوين، الأوضاع، الإنذار، شريط الحالة |
| **Pro** | + الروبوت، الطاقة، الزوار، فحص قبل النوم، خلفية الطقس، برواز الصور، المشاهد السينمائية، ملخص الصبح، خريطة الحرارة، توهّج الغرف، المؤقتات، Fully Kiosk |
| **Premium** | + فاتورة الكهرباء، زر الطوارئ، جدار الكاميرات، ثيمات رمضان والعيد |

## التركيب عن طريق HACS (الطريقة الأساسية)

1. بـ HA: **HACS → ⋮ → Custom repositories**، وحط رابط هاد الـ repo، والنوع **Integration**.
2. ابحث بـ HACS عن **SmartNest Dashboard**، واضغط **Download**.
3. **Restart** لـ HA.
4. **Settings → Devices & services → Add integration → SmartNest Dashboard**.

بعدها كل نسخة جديدة بتطلع عند الزبون كـ **Update** بـ HACS، وبتنزل بضغطة.

لنشر نسخة جديدة (من جهازك):

```bash
./scripts/release.sh 0.3.0 "شو الجديد"
```

## التطوير على جهازك

```bash
npm install
```

```bash
npm run dev
```

افتح `http://localhost:5174/dev/index.html`. فيه أجهزة وهمية ومخطط تجريبي، وأزرار تحت عالشمال:

- **Motion:** حركة بالممر

- **Reset:** يرجّع كل شي من الأول

## التركيب اليدوي (بدون HACS)

1. عند الزبون، ركّب add-on **Advanced SSH & Web Terminal**.
2. من جهازك:

```bash
./scripts/deploy.sh root@IP-تبع-الزبون --restart
```

3. بـ HA: **Settings → Devices & services → Add integration → SmartNest Dashboard**. بيطلع **SmartNest** بالقائمة الجانبية.
4. اعمل للزبون مستخدم **مش أدمن**. هيك ما بيشوف زر التعديل.
5. على تابلت الحيط: سجّل دخول بحساب الزبون، وافتح `/smartnest`. ومن صفحة البروفايل خبّي باقي عناصر القائمة الجانبية.
6. ادخل بحسابك أنت (أدمن)، واضغط ✏️ عشان تعدّل:
   - **⚙️ الإعدادات:** اسم البيت، اللغة، المظهر، الجرس، شاشة التوقف
   - **المخطط:** ارفع الصورة، وبعدين "أضف جهاز" واسحبه لمكانه
   - **حفظ:** كل الشاشات المفتوحة بتتحدّث لحالها

### التحديث

```bash
./scripts/deploy.sh root@IP-تبع-الزبون
```

بعدها بـ HA: **SmartNest → ⋮ → Reload**. رقم النسخة بيطلع بالإعدادات تحت "حول".

لنسخة جديدة، غيّر `version` بـ `package.json` بس. الـ build بينسخه للـ manifest لحاله.

## إعداد ميزات v0.5 عند الزبون

### تابلت الحيط (Fully Kiosk Browser)
1. عالتابلت: ركّب **Fully Kiosk Browser** وفعّل رخصة **PLUS**.
2. بإعدادات Fully:
   - **Remote Administration**: شغّلها وحط password.
   - **Advanced Web Settings → Enable JavaScript Interface**: شغّلها. هيك الداشبورد بيعرف إنه هو التابلت.
   - **Kiosk Mode**: شغّلها، والرمز إلك بس.
3. بـ HA: **Add integration → Fully Kiosk Browser**، وحط IP التابلت والـ password.
4. بالداشبورد: ⚙️ الإعدادات ← "تابلت الحيط". لازم يطلع **✓ هالشاشة هي التابلت**. ومن هون بتظبط:
   - خفّف الإضاءة بالليل
   - اطفي الشاشة بعد قديش
   - صحّي الشاشة لما حدا يقرّب (**اسأل صاحب البيت أول**)

الوقت اللي بيعتبره "ليل" هو نفس أوقات "غامق من/لـ" بالمظهر.

### الأوضاع (طالع / راجع / نوم / سهرة)
1. انسخ [`ha-config/packages/smartnest_modes.yaml`](ha-config/packages/smartnest_modes.yaml) لـ `/config/packages/` عند الزبون.
2. بـ `configuration.yaml`:
   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```
3. عدّل الأسطر اللي عليها ✏️ حسب أجهزة البيت، وبعدين Restart.
4. بالداشبورد: ✏️ ← إضافة عنصر ← **الأوضاع**.

### برواز صور العيلة
الـ integration بيعمل فولدر **Media → My media → smartnest-photos** لحاله. حط فيه صور العيلة، وشاشة التوقف بتصير برواز صور. وإذا الفولدر فاضي، بتضل الساعة.

### خلفية الطقس
بتشتغل لحالها من `weather.forecast_home`. بتقدر تغيّر المصدر أو تطفيها من الإعدادات ← الطقس.

### الغرف بتضوي
✏️ ← على المخطط اضغط **الغرف** ← **ارسم غرفة**. اضغط على كل زاوية، وبعدين على أول زاوية عشان تسكّر الغرفة. الزوايا بتلزق ببعض لحالها بين الغرف الجنب بعض. وأي ضو حاططه جوا الغرفة بيخليها تضوي بلونه.

## إعداد ميزات v1.0 عند الزبون

### شريط الحالة
بيطلع لحاله تحت البار، وبيعدّ **بس الأجهزة اللي على الداشبورد**. من ⚙️ ← شريط الحالة بتقدر تخبّي أي نوع، أو تختار حساس استهلاك البيت.

### كرت الترحيب والصلاة وملخص الصبح
- كبّر عنصر **الساعة** لـ 4 صفوف أو أكثر، بيصير كرت ترحيب فيه الطقس والصلاة الجاية.
- **مواعيد الصلاة:** ركّب integration الـ **Islamic Prayer Times** واختار طريقة الحساب حسب البلد. وبتقدر تطفيها من ⚙️ للزبون اللي ما بدّه إياها.
- **ملخص الصبح:** بيطلع مرة باليوم، أول ما حدا يلمس التابلت الصبح بعد وقت "الغامق".

### صفحة الروبوت (Roborock)
✏️ ← صفحة جديدة ← **الروبوت**، أو إضافة عنصر ← روبوت التنظيف.
- **الغرف بتيجي من Roborock لحالها** (`roborock.get_maps`).
- إذا ما زبطت، بتطلع غرف HA وبيستعمل `vacuum.clean_area`. هاد بده **HA 2026.3** أو أحدث، وبده تربط غرف الروبوت بغرف HA من: إعدادات entity الروبوت ← Clean by area ← Configure areas.
- ضغطة مطوّلة عالروبوت بأي مكان بتفتح نفس الصفحة.

### مين دق الجرس
بالإعدادات ← الجرس: اختار زر الجرس والكاميرا. الـ integration بيحفظ صورة مع كل دقة، **حتى لو ما في شاشة مفتوحة**، وبيمسحها بعد عدد الأيام اللي بتحدده (الافتراضي 7). ضيف عنصر **الزوار** على صفحة الجرس.

### الطاقة
عنصر **الطاقة** بيحاول يلاقي حساسات الشمسي والشبكة والبطارية لحاله. إذا ما لقاها، اختارها من إعدادات العنصر. وإذا الاتجاه طلع بالعكس، استعمل "اعكس الاتجاه".

### صحة النظام و Telegram
⚙️ ← **صحة النظام**: الأجهزة الطافية، والبطاريات، والـ backup، والتحديثات، وحالة الجهاز، وقطع الروبوت، والتابلتات مع زر إعادة تحميل.
للتنبيهات على جوالك: [`ha-config/packages/smartnest_health.yaml`](ha-config/packages/smartnest_health.yaml). الخطوات مكتوبة بأول الملف: بوت Telegram واحد لكل زباينك.

## إعداد ميزات الدفعة 1 (Premium)
- **زر الطوارئ:** انسخ [`ha-config/packages/smartnest_safety.yaml`](ha-config/packages/smartnest_safety.yaml)، وعدّل الأسطر اللي عليها ✏️، وضيف عنصر **طوارئ**. لازم تضل ضاغط عليه ثانيتين.
- **فاتورة الكهرباء:** عنصر بيقرأ إحصائيات HA. اختار عداد الاستهلاك، وحط سعر الكيلوواط والعملة من إعدادات العنصر.
- **الإنذار:** أي `alarm_control_panel` بيشتغل لحاله. ضغطة عليه بتفتح أزرار التشغيل، والإطفاء بالرمز.
- **فحص قبل النوم:** عنصر بيفحص الأقفال والأبواب والشبابيك والأضواء والإنذار والأجهزة الخطرة (المكواة، الفرن، السخان... بيعرفها من اسمها).
- **المؤقتات:** بنافذة أي جهاز شغّال: "طفّي بعد 15 دقيقة، 30 دقيقة، ساعة، ساعتين". بتشتغل على HA نفسه، فبتكمل حتى بعد الـ restart.
- **الغرف:** ضغطة على غرفة بالمخطط بتفتح أجهزتها، وفيها زر لكل الأضواء.
- **رمضان والعيد:** تلقائي من التقويم الهجري، أو بتختاره يدوي من الإعدادات.

## كيف بيشتغل

| الشي | التفاصيل |
|---|---|
| **الإعدادات** | محفوظة بـ `.storage/smartnest.dashboard`، وبتدخل بالـ backup |
| **صور المخطط** | `/config/smartnest/floorplans/`، بأسماء عشوائية (128-bit) |
| **الصلاحيات** | الكل بيقرأ، والأدمن بس بيحفظ وبيرفع (الفحص على السيرفر، مش بس بالواجهة) |
| **صور الزوار** | `/config/smartnest/visitors/`، بأسماء عشوائية، وبتنمسح لحالها بعد كم يوم |
| **الكاميرات** | صورة بتتحدّث كل 10 ثواني، وبث مباشر MJPEG لما تفتح الكاميرا. بيشتغل مع أي كاميرا بيعرفها HA |
| **الجرس** | entity من نوع `event.*` أو `binary_sensor.*`. لما يدق، بتطلع نافذة على كل الشاشات المفتوحة |
| **القفل** | ما بينفتح بضغطة وحدة أبدًا. لازم ضغطتين، والثانية لازم تكون خلال 4 ثواني |
| **قفل الشاشة (kiosk)** | زر 🔒 بالبار بيخبّي قائمة HA وبيمنع الخروج من الداشبورد إلا بالرمز. الرمز إلك، وبتحطه من الإعدادات. القفل لكل جهاز لحاله. **قفل للبيت (أولاد وضيوف)، مش حماية أمنية**: للقفل الكامل استعمل Fully Kiosk Browser أو Guided Access |
| **اللغات** | عربي، إنجليزي، عبري. RTL كامل، بس المخطط ما بينقلب |
| **الخطوط والأيقونات** | Rubik (فيه عربي وعبري) وMDI، من الـ Design System |

### لازم تعرفها
- **صور المخطط بتنفتح بدون تسجيل دخول** لأي حدا بيوصل لـ HA وبيعرف اسم الملف (الاسم عشوائي وما بينخمّن). هاد نفس سلوك `/local` بـ HA. ما في صور كاميرات هون.
- ملفات **SVG ممنوعة** بالرفع، لأنها ممكن تحمل سكربت.
- لما تغيّر صورة مخطط، القديمة بتضل على الديسك. (التنظيف بنسخة جاية.)
