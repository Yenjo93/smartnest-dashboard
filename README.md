# SmartNest Dashboard

داشبورد لزباين Home Assistant: مخطط البيت عليه الأجهزة، وصفحات بتنبني من عناصر، وستايل Apple بهوية SmartNest.

> **EN:** A Home Assistant dashboard panel with an interactive floor plan, Apple-style controls, Arabic/English/Hebrew (RTL), a doorbell popup and a PIN-protected kiosk lock. Install through HACS as a custom repository (category: Integration), then add the "SmartNest Dashboard" integration.

## التفعيل (لكل بيت كود)

الداشبورد ما بيشتغل بدون **كود تفعيل** مربوط ببيت واحد. أنت لحالك بتقدر تطلّع الكود.

1. عند الزبون، افتح SmartNest. بيطلعلك **رقم التركيب**، انسخه.
2. على جهازك:
   ```bash
   node scripts/license.mjs <رقم-التركيب> "بيت أبو محمد"
   ```
3. حط الكود اللي طلع (بيبلّش بـ `SN1.`) بشاشة التفعيل، واضغط **فعّل**. لازم تكون داخل بحساب أدمن.

- **المفتاح السري** موجود بـ `~/.smartnest/license-private.pem` على جهازك بس، ومش بالـ repo. **اعمله backup** (مثلاً بمدير كلمات السر): إذا ضاع، ما بتقدر تطلّع أكواد جديدة، وإذا حدا أخذه، بيقدر يطلّع أكواد.
- الكود **لبيت واحد بس**. إذا حدا نسخه لبيت ثاني، ما بيزبط.
- ما في سيرفر ولا إنترنت: التحقق بيصير جوا HA الزبون.
- **حدود الحماية:** الكود ظاهر بالـ repo العام، فمبرمج شاطر بيقدر يعدّل الملفات ويشيل الفحص. هاد بيمنع الاستعمال العادي، مش الاختراق المقصود.

### الباقات والاشتراكات
```bash
node scripts/license.mjs <رقم> "الاسم" --plan basic           # أساسي
node scripts/license.mjs <رقم> "الاسم" --plan pro --days 365  # Pro لسنة
node scripts/license.mjs <رقم> "الاسم" --trial                # تجربة Premium لـ 14 يوم
node scripts/license.mjs <رقم> "الاسم" --reseller "شركة نور"   # كود لموزّع
```
بدون `--plan` بتطلع Premium، وبدون `--days` ما بتنتهي. قبل الانتهاء بأسبوعين الأدمن بيشوف تذكير. ولما يخلص الاشتراك، بترجع شاشة التفعيل لحد ما تحط كود جديد.

| الباقة | شو بتفتح |
|---|---|
| **أساسي** | المخطط، الأجهزة، الكاميرات، الساعة، العناوين، الأوضاع، الإنذار، شريط الحالة |
| **Pro** | + الروبوت، الطاقة، الزوار، فحص قبل النوم، خلفية الطقس، برواز الصور، المشاهد السينمائية، ملخص الصبح، خريطة الحرارة، توهّج الغرف، المؤقتات، Fully Kiosk |
| **Premium** | + فاتورة الكهرباء، زر الطوارئ، جدار الكاميرات، ثيمات رمضان والعيد |

### صفحة التراخيص ببيتك (الأسهل)
صفحة منفصلة بالقائمة الجانبية بـ Home Assistant تبعك، بتطلع منها مفاتيح للزباين من أي مكان (حتى من الجوال):
1. بـ SmartNest ببيتك: ✏️ ← ⚙️ ← **التراخيص**.
2. **اختار الملف**: `license-private.pem` من فولدر `~/.smartnest` على الكمبيوتر.
3. بتطلع صفحة **التراخيص 🔑** بالقائمة الجانبية: مفتاح جديد، قائمة البيوت، جدّد، غيّر الباقة، وابعت عالواتساب.

- **بتطلع بس ببيتك وللأدمن بس.** عند الزباين ما بتطلع، لأنه ما عندهم المفتاح.
- المفتاح محفوظ جوّا HA، فبيدخل بالـ backup. خلّي الـ backups تبعتك بمكان آمن، ولا تعطي حدا حساب أدمن ببيتك.
- بتقدر تشيله بأي وقت من أسفل صفحة التراخيص.

### مكتب التراخيص (إلك بس)
```bash
npm run licenses
```
بيفتح صفحة بالمتصفح على جهازك بس (127.0.0.1)، وبتشتغل بالمفتاح السري اللي بـ `~/.smartnest`:
- **مفتاح جديد:** رقم التركيب من شاشة التفعيل عند الزبون، الاسم، الباقة، والمدة. المفتاح بينسخ لحاله، وفي زر يبعته للزبون عالواتساب مع طريقة التفعيل.
- **كل البيوت بقائمة:** الباقة، لحد إيمتى، وتنبيه للي قرّبوا يخلصوا. وفي بحث وفلتر "قرّبت" و"خلصت".
- **جدّد سنة** أو **غيّر الباقة** بكبسة، وبيطلع مفتاح جديد لنفس البيت.
- **أضف مفتاح قديم:** الصق مفتاح عملته قبل (من الـ Terminal)، وبينضاف للقائمة.
- القائمة محفوظة بـ `~/.smartnest/issued.json`، ومش بالـ repo. خليها مع نسخة المفتاح السري.

## التركيب عن طريق HACS (الطريقة الأساسية)

1. بـ HA: **HACS → ⋮ → Custom repositories**، وحط رابط هاد الـ repo، والنوع **Integration**.
2. ابحث بـ HACS عن **SmartNest Dashboard**، واضغط **Download**.
3. **Restart** لـ HA.
4. **Settings → Devices & services → Add integration → SmartNest Dashboard**.

بعدها كل نسخة جديدة بتطلع عند الزبون كـ **Update** بـ HACS، وبتنزل بضغطة.

لنشر نسخة جديدة (من جهازك):

```bash
./scripts/release.sh 0.3.0 "شو الجديد"
```

## التركيب اليدوي (بدون HACS)

1. عند الزبون، ركّب add-on **Advanced SSH & Web Terminal**.
2. من جهازك:

```bash
./scripts/deploy.sh root@IP-تبع-الزبون --restart
```

3. بـ HA: **Settings → Devices & services → Add integration → SmartNest Dashboard**. بيطلع **SmartNest** بالقائمة الجانبية.
4. اعمل للزبون مستخدم **مش أدمن**. هيك ما بيشوف زر التعديل.
5. على تابلت الحيط: سجّل دخول بحساب الزبون، وافتح `/smartnest`. ومن صفحة البروفايل خبّي باقي عناصر القائمة الجانبية.
6. ادخل بحسابك أنت (أدمن)، واضغط ✏️ عشان تعدّل:
   - **⚙️ الإعدادات:** اسم البيت، اللغة، المظهر، الجرس، شاشة التوقف
   - **المخطط:** ارفع الصورة، وبعدين "أضف جهاز" واسحبه لمكانه
   - **حفظ:** كل الشاشات المفتوحة بتتحدّث لحالها

### التحديث

```bash
./scripts/deploy.sh root@IP-تبع-الزبون
```

بعدها بـ HA: **SmartNest → ⋮ → Reload**. رقم النسخة بيطلع بالإعدادات تحت "حول".

لنسخة جديدة، غيّر `version` بـ `package.json` بس. الـ build بينسخه للـ manifest لحاله.

## إعداد ميزات v0.5 عند الزبون

### تابلت الحيط (Fully Kiosk Browser)
1. عالتابلت: ركّب **Fully Kiosk Browser** وفعّل رخصة **PLUS**.
2. بإعدادات Fully:
   - **Remote Administration**: شغّلها وحط password.
   - **Advanced Web Settings → Enable JavaScript Interface**: شغّلها. هيك الداشبورد بيعرف إنه هو التابلت.
   - **Kiosk Mode**: شغّلها، والرمز إلك بس.
3. بـ HA: **Add integration → Fully Kiosk Browser**، وحط IP التابلت والـ password.
4. بالداشبورد: ⚙️ الإعدادات ← "تابلت الحيط". لازم يطلع **✓ هالشاشة هي التابلت**. ومن هون بتظبط:
   - خفّف الإضاءة بالليل
   - اطفي الشاشة بعد قديش
   - صحّي الشاشة لما حدا يقرّب (**اسأل صاحب البيت أول**)

الوقت اللي بيعتبره "ليل" هو نفس أوقات "غامق من/لـ" بالمظهر.

### الأوضاع (طالع / راجع / نوم / سهرة)
1. انسخ [`ha-config/packages/smartnest_modes.yaml`](ha-config/packages/smartnest_modes.yaml) لـ `/config/packages/` عند الزبون.
2. بـ `configuration.yaml`:
   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```
3. عدّل الأسطر اللي عليها ✏️ حسب أجهزة البيت، وبعدين Restart.
4. بالداشبورد: ✏️ ← إضافة عنصر ← **الأوضاع**.

### برواز صور العيلة
الـ integration بيعمل فولدر **Media → My media → smartnest-photos** لحاله. حط فيه صور العيلة، وشاشة التوقف بتصير برواز صور. وإذا الفولدر فاضي، بتضل الساعة.

### خلفية الطقس
بتشتغل لحالها من `weather.forecast_home`. بتقدر تغيّر المصدر أو تطفيها من الإعدادات ← الطقس.

### الغرف بتضوي
✏️ ← على المخطط اضغط **الغرف** ← **ارسم غرفة**. اضغط على كل زاوية، وبعدين على أول زاوية عشان تسكّر الغرفة. الزوايا بتلزق ببعض لحالها بين الغرف الجنب بعض. وأي ضو حاططه جوا الغرفة بيخليها تضوي بلونه.

## إعداد ميزات v1.0 عند الزبون

### شريط الحالة
بيطلع لحاله تحت البار، وبيعدّ **بس الأجهزة اللي على الداشبورد**. من ⚙️ ← شريط الحالة بتقدر تخبّي أي نوع، أو تختار حساس استهلاك البيت.

### كرت الترحيب والصلاة وملخص الصبح
- كبّر عنصر **الساعة** لـ 4 صفوف أو أكثر، بيصير كرت ترحيب فيه الطقس والصلاة الجاية.
- **مواعيد الصلاة:** ركّب integration الـ **Islamic Prayer Times** واختار طريقة الحساب حسب البلد. وبتقدر تطفيها من ⚙️ للزبون اللي ما بدّه إياها.
- **ملخص الصبح:** بيطلع مرة باليوم، أول ما حدا يلمس التابلت الصبح بعد وقت "الغامق".

### صفحة الروبوت (Roborock)
✏️ ← صفحة جديدة ← **الروبوت**، أو إضافة عنصر ← روبوت التنظيف.
- **الغرف بتيجي من Roborock لحالها** (`roborock.get_maps`).
- إذا ما زبطت، بتطلع غرف HA وبيستعمل `vacuum.clean_area`. هاد بده **HA 2026.3** أو أحدث، وبده تربط غرف الروبوت بغرف HA من: إعدادات entity الروبوت ← Clean by area ← Configure areas.
- ضغطة مطوّلة عالروبوت بأي مكان بتفتح نفس الصفحة.

### مين دق الجرس
بالإعدادات ← الجرس: اختار زر الجرس والكاميرا. الـ integration بيحفظ صورة مع كل دقة، **حتى لو ما في شاشة مفتوحة**، وبيمسحها بعد عدد الأيام اللي بتحدده (الافتراضي 7). ضيف عنصر **الزوار** على صفحة الجرس.

### الطاقة
عنصر **الطاقة** بيحاول يلاقي حساسات الشمسي والشبكة والبطارية لحاله. إذا ما لقاها، اختارها من إعدادات العنصر. وإذا الاتجاه طلع بالعكس، استعمل "اعكس الاتجاه".

### صحة النظام و Telegram
⚙️ ← **صحة النظام**: الأجهزة الطافية، والبطاريات، والـ backup، والتحديثات، وحالة الجهاز، وقطع الروبوت، والتابلتات مع زر إعادة تحميل.
للتنبيهات على جوالك: [`ha-config/packages/smartnest_health.yaml`](ha-config/packages/smartnest_health.yaml). الخطوات مكتوبة بأول الملف: بوت Telegram واحد لكل زباينك.

## وضع سريع (للتابلتات الضعيفة)
اضغط لوجو SmartNest ← هالشاشة ← **وضع سريع**: تلقائي / شغّال / طافي. كل شاشة إلها إعدادها.
- **كروت مصمتة بدل التغبيش الحيّ:** هاد أكبر إشي بياكل من التابلت.
- **بدون حركات بالخلفية:** الضو الماشي، الحبيبات، الفصول، الخلفيات، خلفية الطقس، وتنفّس الكروت.
- **تحديث أقل:** الداشبورد بيعيد رسم حاله مرة كل 0.7 ثانية بالأكثر، بدل مع كل تغيير صغير بـ HA. وحتى بالوضع العادي صار في تجميع للتحديثات (0.15 ثانية).
- **تلقائي:** بيشتغل لحاله على التابلتات اللي ذاكرتها 2GB أو أقل، أو 4 أنوية أو أقل.

## جهّز الداشبورد لحاله (للمركّب)
✏️ ← ⚙️ ← **جهّز الداشبورد لحاله** (أول زر بالإعدادات):
1. بيفحص أجهزة البيت، وبيطلّع قائمة بالصفحات اللي بقدر يعبّيها مع كم جهاز بكل وحدة: الرئيسية، الغرف، التكييف، الكهربا، الأمان، الجرس، المي، الروبوت، الموسيقى والتلفزيون. والسيارة والجنينة والحيوانات اختيارية.
2. **الغرف:** صفحة وحدة لكل الغرف، أو **صفحة لكل غرفة** (فوقها كرت الغرفة، وتحتها أجهزتها والكاميرات). الأحسن للفلل الكبيرة.
3. **الصفحات الموجودة:** "بدّلها" أو "خلّيها وزيد". لما تبدّل، المخطط المرسوم بيضل مع كل أجهزته وغرفه.
4. اضغط **جهّز**، وبعدين **حفظ**.

> نصيحة: رتّب الأجهزة على غرف (Areas) بـ HA قبل، وشغّل ستايل 2.0 إذا بدك رئيسية Bento.

## عناصر جديدة (v1.34)

- **المكيّف:** مكيّف واحد كبير، الحرارة على دائرة، حرارة الغرفة، والأوضاع (تبريد، تدفئة، مروحة، تجفيف، أوتو، طفي) بكبسة.
- **الأضواء** و**الستاير:** كل أضواء أو ستاير غرفة (أو كل البيت) بكرت واحد. كم واحد شغّال، "طفّي الكل" / "فتّح وسكّر الكل"، وكل واحد لحاله. البوابات والكراج مش داخلين.
- **المشاهد:** المشاهد والسكربتات ككبسات كبيرة. بتختار أي وحدة بدك، أو بيجيب أول 8 لحاله.
- **حساس مع رسم:** حساس واحد كبير مع رسم لآخر 24 ساعة.
- **البطاريات:** كل بطاريات البيت، الأضعف أول. بتختار من كم % تعتبر ضعيفة.
- **أوقات الصلاة:** من تكامل Islamic Prayer Times، والصلاة الجاية مع كم باقي.
- **السخان والري:** الجهاز بيتغيّر بس من وضع التعديل (✏️ ← إعدادات العنصر)، مش من الكبس عليه. السخان بيقبل أي switch أو water_heater.
- **اختيار الجهاز صار أسرع وأسهل:** كبسات للغرف فوق، بحث، 40 جهاز وبعدين "اعرض كمان"، والعناصر التقنية (firmware، إشارة…) مخبّاية إلا إذا طلبتها. والإعدادات ما عادت ترسم حالها من جديد مع كل تغيير بالبيت.
- صار في إعدادات لعناصر **الري**، **الهوا** (المنقّي والحساسات)، **الطريق للشغل** (أي حساسات)، و**كاميرات Frigate** (أي كاميرا).

## ارسم المخطط (v1.41)

بوضع التعديل، بأدوات المخطط:
- **ارسم المخطط:** اسحب على الشبكة لترسم كل غرفة (بتلزق بحيطان الغرف اللي جنبها)، اكبس على غرفة لتسمّيها وتختار أرضيتها (خشب، بلاط، عادي، برّا) أو تحركها وتكبّرها من الزوايا. "أبواب": اكبس على حيط لتحط باب. "حفظ" بيطلّع مخطط نظيف زي الديمو.
- إذا في صورة مخطط (من المهندس)، بتبين خفيفة تحت لترسم فوقها.
- **نظّف المخطط:** إذا الغرف محددة على الصورة (الغرف أو إضافة تلقائية)، كبسة وحدة بتحوّلها لمخطط نظيف بنفس الشكل. الأجهزة بتضل بمكانها.
- **رجّع الصورة:** بيرجّع صورة المخطط الأصلية.

## للمركّب (v1.40)

- **اسمك ولوجوك عند كل الزباين** (2.0): صفحة التراخيص ← "🏷️ اسمك ولوجوك". بيطلعوا بدل SmartNest بالشريط وشاشة التوقف بكل البيوت مع النبض. أو لبيت واحد: الإعدادات ← المركّب ← اللوجو.
- **QR للموبايل:** اللوجو ← حول: امسحه بالموبايل ليفتح الداشبورد (الأحسن بتطبيق Home Assistant).
- **تقرير للزبون على واتساب:** بصفحة التراخيص "📋 تقرير" جنب كل بيت عنده رقم: شغّال ولا لا، الأجهزة الفاصلة، البطاريات، النسخة الاحتياطية، وتاريخ الاشتراك.
- **نوع المكان** بـ"جهّز الداشبورد لحاله": شقة، فيلا، مكتب، وكل وحدة بتختار الصفحات المناسبة.
- **ابعت تصميم لبيت ثاني:** "🎨 ابعت تصميم" (تصميم بيتك أو ملف مصدّر). بيوصل مع النبض وبيستنى موافقة الأدمن عند الزبون. الأجهزة اللي مش موجودة عنده بتنشال، ومخططه هو بيضل.

- **مركز الإشعارات 🔔:** إشعارات HA (مع الرقم)، وآخر 24 ساعة من الأبواب والأقفال والإنذار والتسريب.

- **جدار الكاميرات:** الكاميرا اللي فيها حركة بتطلع أول وأكبر مع إطار أحمر.
- **مشغّل صغير عائم:** لما في موسيقى شغّالة، صورة الأغنية والاسم وإيقاف/التالي من أي صفحة.
- **شاشة التوقف:** "طفّيهم" للأضواء و"اقفلهم" للأقفال بدون ما تصحّي الشاشة.
- **عدّاد على الكروت:** "بيطفي بعد 30 د" أو الوقت الباقي للغسالة والنشافة.

## أنعم وأسرع (v1.36)

- كل كرت بيرسم حاله بس لما أجهزته تتغيّر (قبل كان كل الكروت ترسم مع كل تغيير بالبيت).
- الملف انقسم: الداشبورد بيفتح بأقل، والإعدادات والمخطط 3D وصفحة التراخيص بينزلوا لما تفتحهم.
- بيفتح فوراً على آخر شكل محفوظ على الجهاز، وبعدين بيتحدّث من HA.
- آخر صفحتين فتحتهن بيضلّوا جاهزين: الرجعة إلهم فورية.
- الكاميرات بتوقف تتحدّث إذا مش ظاهرة، والصورة الجديدة بتطلع كاملة بدل ما تنرسم شوي شوي.
- الضو بيتغيّر على الشاشة لحظة الكبسة، وبيرجع إذا الجهاز ما استجاب.
- اسحب الشيت من فوق لتحت لتسكّره، والصفحات والسحب بيرجعوا بحركة نابض.
- السلايدرز والدائرة صاروا يلحقوا الإصبع بدون تقطيع.
- الصور اللي بترفعها بتصغر لحالها (WebP، 2560px) قبل ما تنرفع.
- شريط صغير فوق إذا انقطع الاتصال بـ HA، وبيختفي لما يرجع.

## حجب أجهزة من الداشبورد

⚙️ الإعدادات ← **أجهزة مخفية** ← "احجب جهاز". أو بوضع التعديل افتح الجهاز واكبس "احجبه من الداشبورد".
الجهاز المحجوب بيختفي من كل مكان: الصفحات، المخطط، البحث، شريط الحالة، الصفحات اللي بتنعمل لحالها، وقوائم اختيار الأجهزة. بيضل شغّال بـ Home Assistant عادي، وبوضع التعديل بتشوف كروته لتقدر تشيلها. لترجّعه اكبس عليه بنفس القائمة.

## التعبئة التلقائية من HA
- **صفحة الغرف:** ✏️ ← صفحة جديدة ← **الغرف**. بتقرأ الغرف (Areas) من HA، وبتحط تحت كل غرفة كل أجهزتها. والـ entities التقنية (diagnostic وconfig) والمخفية ما بتنحط.
- **المخطط:** بعد ما ترسم الغرف (بنفس أسماء غرف HA)، اضغط **عبّي الغرف**، وكل جهاز بيروح لغرفته لحاله.
- **التركيب الجديد:** المعالج بيعمل صفحة الغرف لحاله.
- **نصيحة:** رتّب الأجهزة على غرف بـ HA أول (Settings ← Areas)، بتطلع التعبئة أحسن بكثير.

## اكتشاف الغرف من صورة المخطط
1. ارفع صورة المخطط (أحسن إشي المخطط اللي بتطلّعه تطبيقات الجوال زي Magicplan أو RoomPlan: حيطان غامقة، وكل غرفة إلها لون فاتح).
2. ✏️ ← **إضافة تلقائية** ✨ (كبسة وحدة بتعمل كل إشي: بتكتشف الغرف، بتسمّيها، وبتحط الأجهزة). بيرسم حدود كل غرفة لحاله، والأثاث الملوّن (تخت، سجادة) ما بينحسب غرفة.
3. **الأسماء:** إذا في AI Task بـ HA (OpenAI أو Gemini أو Claude أو Ollama، HA 2025.8 وأحدث)، بيقرأ اسم كل غرفة عن المخطط وبيربطه بغرفة HA المناسبة، حتى لو المخطط بالإنجليزي والغرف بالعربي. وبعدها الأجهزة بتنزل كل واحد بغرفته.
4. **بدون AI:** بيسألك عن كل غرفة "شو هاي الغرفة؟" وهي مضوية عالمخطط، بتختارها من غرف HA (أو تخطّي)، وبعدها الأجهزة بتنزل لحالها.
5. إذا في غرفة ما انكشفت أو طلعت مش مزبوطة: ارسمها بإيدك أو اسحب زواياها.

## إعداد ميزات الدفعة 1 (Premium)
- **زر الطوارئ:** انسخ [`ha-config/packages/smartnest_safety.yaml`](ha-config/packages/smartnest_safety.yaml)، وعدّل الأسطر اللي عليها ✏️، وضيف عنصر **طوارئ**. لازم تضل ضاغط عليه ثانيتين.
- **فاتورة الكهرباء:** عنصر بيقرأ إحصائيات HA. اختار عداد الاستهلاك، وحط سعر الكيلوواط والعملة من إعدادات العنصر.
- **الإنذار:** أي `alarm_control_panel` بيشتغل لحاله. ضغطة عليه بتفتح أزرار التشغيل، والإطفاء بالرمز.
- **فحص قبل النوم:** عنصر بيفحص الأقفال والأبواب والشبابيك والأضواء والإنذار والأجهزة الخطرة (المكواة، الفرن، السخان... بيعرفها من اسمها).
- **المؤقتات:** بنافذة أي جهاز شغّال: "طفّي بعد 15 دقيقة، 30 دقيقة، ساعة، ساعتين". بتشتغل على HA نفسه، فبتكمل حتى بعد الـ restart.
- **الغرف:** ضغطة على غرفة بالمخطط بتفتح أجهزتها، وفيها زر لكل الأضواء.
- **رمضان والعيد:** تلقائي من التقويم الهجري، أو بتختاره يدوي من الإعدادات.

## إعداد ميزات الدفعة 2 (العيلة)
- **العيلة:** بيقرأ أفراد العيلة (`person.*`) لحاله، مع صورهم ومين بالبيت. وفيه زر **ابعت** بيطلّع رسالة على شاشة الحيط.
- **القائمة:** أي قائمة To-do بـ HA (مثلاً Shopping list). بتتحدّث لحالها من كل الجوالات.
- **التقويم:** كل تقويمات HA (Google، CalDAV، المحلي)، وبتختار أيهم من إعدادات العنصر.
- **طقس الأسبوع** و**العدّاد:** أعياد ميلاد ورحلات، ومعها رمضان والعيدين لحالهم بالعربي.
- **رسائل للشاشة من أوتوميشن:** `smartnest.show_message` (مع `ack` بيطلع زر تأكيد، ولما ينضغط بيصير حدث `smartnest_message_ack`).
- **وضع الأطفال:** بالإعدادات اختار "صفحة الأطفال"، وبيطلع زر 🧸 بالبار. الطلوع منه برمز قفل الشاشة.
- **روتين العيلة:** [`ha-config/packages/smartnest_family.yaml`](ha-config/packages/smartnest_family.yaml): تذكير الدوا (بيعيد كل 10 دقايق لحد ما حدا يضغط "أخذته")، تنبيه إذا ما في حركة عند كبار السن، طفي التلفزيون وقت النوم، الأذان على السماعات.
- **صور من Google Photos أو غيره:** بفولدر الصور حط عنوان `media-source://...` كامل بدل اسم الفولدر.

## إعداد ميزات الدفعة 3 (الأتمتة)
- **محرر الأتمتة بالعربي:** ⚙️ ← **الأتمتة** (للأدمن). "لما (وقت / شروق أو غروب / جهاز يتغير / وضع البيت) ← اعمل (شغّل / طفّي / وضع / رسالة)". بتقدر تختار أيام، ووقت محدد بس. بتنحفظ كأتمتة عادية بـ HA، وفيها زر تشغيل وإطفاء، وتعديل، وحذف.
- **الجداول:** عنصر بيرسم كل الأتمتة المربوطة بوقت على أسبوع كامل، مع خط "هلأ".
- **المقياس:** لخزان المي، جرة الغاز، أو أي نسبة. بيحمرّ لما يقرّب يخلص.
- **البوابة:** كاميرا وزر بتضل ضاغط عليه ثانية عشان تفتح أو تسكّر.
- **آخر اللي انشاف (Frigate):** أشخاص، سيارات، حيوانات، طرود. وإذا Frigate تعرّف على وجه أو لوحة، بيبيّن الاسم أو الرقم. محتاج integration الـ Frigate.
- **سجل القفل:** آخر الحركات بنافذة القفل.
- **روتين الراحة:** [`ha-config/packages/smartnest_routines.yaml`](ha-config/packages/smartnest_routines.yaml): هدوء وقت الصلاة، السحور، نوم وصحيان تدريجي، "أنا راجع"، الباب مفتوح من 10 دقايق، محاكاة وجود بالسفر، ري حسب المطر، وضع التوفير، وزر الحيط.

## إعداد ميزات الدفعة 4 (الشكل)
- **لون السما:** الخلفية بتاخذ لون السما الحقيقي حسب الشمس (`sun.sun`): زهري بالفجر، ذهبي قبل الغروب، أزرق بالنهار، وكحلي بالليل. وتغيير الثيم بين الليل والنهار بيصير بانتقال ناعم.
- **مخطط 3D:** زر 🧊 على المخطط بيميّله، والأجهزة بتوقف عليه.
- **خرائط الهوا:** زر الحرارة بيتنقل بين حرارة، رطوبة، وCO₂ (حسب الحساسات الموجودة جوا الغرف).
- **العيلة على المخطط:** إذا عندك حساسات غرف (Bermuda أو ESPresense) زي `sensor.abu_mohammad_area` = "الصالة"، صورة الشخص بتطلع بغرفته.
- **شاشة التوقف:** 3 أشكال (كلاسيك، بسيط، عقارب)، وبتقبل فيديوهات كمان، مش بس صور.
- **زجاج سائل:** شكل كروت أفخم من الإعدادات.
- **وضع الضيوف:** بالإعدادات حط اسم شبكة الضيوف وكلمة سرها، وبيطلع زر بالبار. لما تشغّله، بيطلع ترحيب مع QR للواي فاي، حتى على شاشة التوقف. (كلمة السر بتنحفظ بإعدادات الداشبورد، فاستعمل شبكة ضيوف مش شبكتك الأساسية.)
- **القفل بيلف 3D** لما ينقفل أو ينفتح، والغرف المضوية "بتتنفّس" ببطء.

## إعداد ميزات الدفعة 5 (الأجهزة وأدوات المركّب)
- **الموسيقى والتلفزيون:** عنصر بيبيّن صورة الأغنية وأزرار التحكم والصوت، و"شغّل بكل البيت" للسماعات اللي بتدعم المجموعات.
- **ريموت التلفزيون:** أسهم وOK ورجوع والرئيسية والصوت. بيشتغل مع Android TV وSamsung وLG وApple TV وRoku، وبيعرف نوع التلفزيون لحاله.
- **وضع السينما:** زر بعنصر الموسيقى بيعمل مشهد سينما، وبيخفّف إضاءة التابلت، وبيشغّل `script.smartnest_cinema` إذا موجود.
- **الإعلان عالسماعات:** بالإعدادات اختار السماعات، وبنافذة "ابعت رسالة" بيطلع خيار "قولها عالسماعات" (Google Translate TTS بيحكي عربي).
- **النقل بين البيوت:** ⚙️ ← صدّر الداشبورد (ملف JSON)، وبالبيت الجديد استورده. المخطط والغرف والصفحات كلها بتنتقل.
- **معالج التركيب:** أول ما تضيف الـ integration ببيت جديد بيسألك: الاسم واللغة، وبعدين نوع البيت (شقة، فيلا، مكتب)، وبيبني الصفحات لحاله.
- **الصيانة:** مهام بتتكرر (فلتر المكيف كل 90 يوم...)، وبصحة النظام بيبيّن شو صار وقتها أو تأخر. وكمان "انقطعت هالأسبوع" لكل جهاز.
- **عن الداشبورد:** اضغط على لوجو SmartNest بالبار. هون الزبون بيقيّمك (والتقييم بيوصلك على Telegram)، وكل شاشة بتختار الصفحة اللي بتفتح عليها، و"خط كبير" للتلفزيون.
- **إشعارات الجوال:** [`ha-config/packages/smartnest_notify.yaml`](ha-config/packages/smartnest_notify.yaml): الجرس مع صورة وزر "افتح الباب"، NFC عالباب، تقرير شهري بالإيميل، وتحويل التقييم.
- **بيت للعرض (لفيديوهاتك):** `npm run demo` بيفتح بيت وهمي كامل بكل الميزات.

بدها **AI Task** بـ HA (OpenAI أو Gemini أو Claude أو Ollama، HA 2025.8 وأحدث). بدونه كل إشي بيشتغل عادي، بس بدون الإضافات الذكية.
- **المساعد ✨:** زر بالبار. بتكتب أو بتحكي "طفّي كل الأضواء" أو "قديش الحرارة؟"، وبيرد. بيستعمل Assist بـ HA (والـ AI إذا حاطه بالـ pipeline).

- **اقتراحات من عاداتكم:** ⚙️ ← الأتمتة. بيقرا آخر أسبوعين وبيلاقي اللي بتعملوه بالإيد كل يوم بنفس الوقت، وبكبسة بيصير أتمتة. (هاد ما بدو AI.)

## الـ 30 الجديدة · الدفعة 2: الكهرباء والمي
- **ميزانية الشهر:** بإعدادات عنصر "الكهرباء هالشهر" حط الميزانية. بيطلع شريط قديش صرفت، وعلامة وين رايح آخر الشهر، وتحذير "رح تتعدّاها بـ ₪11". وتحتها رسمة لكل يوم بالشهر.
- **مين بيسحب كهربا هلأ:** عنصر جديد بيقرا حساسات الاستهلاك تبع كل جهاز (قوابس ذكية). دائرة لأكبر 6، والأجهزة اللي طافية وبتسحب كهربا عليها علامة **"ساحب وهو طافي"**.
- **تنبيه الحمل العالي:** ⚙️ ← حط **حد الاستهلاك** (مثلاً 6000 واط). إذا البيت تعدّاه 20 ثانية، بيطلع تنبيه فوق فيه أكبر 3 أجهزة مع زر "طفّي" لكل واحد.
- **المي:** عنصر وصفحة جديدة (صفحة جديدة ← **المي**): عداد المي، الخزان، التسريب، وزر يسكّر المحبس (ضغطتين).
- **الشمس:** إذا في شمس زيادة (أكثر من 1.2 kW)، عنصر الطاقة بيقلك "وقت منيح للغسالة أو السخان".

## الـ 30 الثانية · الدفعة 5: الكهرباء وإلك كمركّب
- **ساعات الكهربا الرخيصة:** ⚙️ ← فعّلها وحط ساعات الرخص والذروة. بتطلع شريحة "ساعة ذروة ⚡" أو "الكهربا رخيصة هلأ"، وبنافذة أي مفتاح زر **"شغّله الساعة 23:00 (أرخص)"**، وHA بيشغّله لحاله.

  - **تجديد عن بعد:** "جدّد سنة" أو "غيّر الباقة" والمفتاح الجديد بيوصل للبيت لحاله مع النبض الجاي (خلال 3 ساعات)، بدون ما تبعتله إشي. حتى لو البيت مقفول لأنه خلص، بيفتح لحاله أول ما يوصل المفتاح. البيوت اللي لسا ما اتصلت (نسخة قديمة أو بدون إنترنت): المفتاح بينسخ وبتبعته إنت.

  - **"تحقّق هلأ":** بالإعدادات ← حول، وعلى شاشة القفل: البيت بيتصل فيك فوراً بدل ما يستنى 3 ساعات. والداشبورد صار يحدّث الباقة والتاريخ لحاله (ما ضل يقول "تجربة" بعد التجديد).
  - **Cloudflare / DuckDNS بدل Nabu Casa:** افتح صفحة التراخيص من دومينك (https) والرابط بيطلع عليه، أو اكتب الدومين بخانة "عنوان HA تبعك من برا". اكبس "جرّب الرابط": إذا Cloudflare مسكّره (403)، بـ Security ← WAF اعمل قاعدة Skip للمسار `/api/webhook/`، وطفّي Bot Fight Mode، وإذا عندك Cloudflare Access استثني نفس المسار.
  - بيبعت مع مفتاح الترخيص تبع البيت، فبيوصلك بس من بيوت إنت مرخّصها.
  - بدها رابط خارجي لـ HA تبعك (Nabu Casa أو دومين).
- **الكفالات:** بصفحة صحة النظام: الجهاز، تاريخ الشراء، مدة الكفالة، وصورة الفاتورة. والقريبة تخلص بتطلع بالأحمر.
- **بطاريات قرّبت تخلص:** بصفحة صحة النظام: من استهلاك آخر شهر، "بطارية حساس الباب بتخلص بعد ~21 يوم".

- **افتتاحية بالشعار:** وهو بيحمّل، العش بينزل بحركة زنبرك، وبيضوي ضو دافي وراه، وبعدين بيطلع اسم SmartNest. لما يخلص، الداشبورد بيبان بنعومة.
- **انتقالات سينمائية:** بستايل 2.0 الصفحة الجديدة بتدخل بعمق (بتكبر شوي وبتستقر)، مش بس بتنزلق.
- **وضع التعديل بيرجف:** العناصر بترجف زي الآيفون لما تعدّل.
- **معرض العناصر الحيّ:** بـ"إضافة عنصر" بتشوف نسخة حيّة مصغّرة من العنصر قبل ما تضيفه.
- **أصوات خفيفة:** ⚙️ ← الصوت والحركة: صوت تيك لما تشغّل، وتوك أوطى لما تطفّي، وصوت قفل. وفي 3 نغمات للجرس (كلاسيكي، دينغ دونغ، نغمة)، وبتسمعها لما تختارها.
- **هياكل تحميل لامعة:** مكان كل إشي بيتحمّل بيلمع، بدل كلمة "جار التحميل".
- **رسومات للحالات الفاضية:** بيت صغير نايم تحت النجوم بدل "ما في أجهزة".

## SmartNest 2.0 · الدفعة 5: المخطط والتفاصيل
- **مجسّم البيت 3D:** زر 🏘️ عالمخطط. الحيطان بتطلع من الغرف المرسومة وبيصير البيت مجسّم بزاوية. الغرف المضوية بتضوي بلون الضو، والأجهزة بتطفي فوق مكانها، وضغطة على أي واحد بتفتحه.
- **المخطط بالليل:** بستايل 2.0 والوضع الغامق، صورة المخطط بتعتم، والأضواء الشغّالة بتعمل هالات ضو واقعية على الأرض.
- **عدسة المخطط 🔍:** زر عالمخطط. بتمرّر إصبعك فوق المخطط، وبتطلع عدسة مكبّرة 2.5 مرة مع اسم الغرفة.
- **مستويات الحركة:** ⚙️ ← الصوت والحركة: كاملة، خفيفة (بتوقف الحركة اللي بتتكرر)، أو بدون (كمان بدون حركة الصفحات). وفي كمان **تباين أعلى**: نص أوضح وكروت مصمتة.
- **كروت بتتنفّس:** بستايل 2.0 الأجهزة الشغّالة بتنبض ببطء بلونها.

## SmartNest 2.0 · لمسات مميزة
كلهم مع ستايل 2.0، ومعظمهم من ⚙️ ← الستايل:
- **شباك عالجنينة:** اختار كاميرا برا، وبثّها المغبّش بيصير خلفية الداشبورد (بيتحدّث كل 15 ثانية).
- **ألوان الموسيقى:** وقت ما في أغنية شغّالة، غلافها بيصير الخلفية، والألوان بتطلع منه.
- **أهلين بالبيت:** لما حدا من العيلة يوصل، بتطلع صورته و"أهلين أم محمد 👋" لست ثواني.
- **خط الحالة:** خط رفيع تحت البار: ذهبي هادي، أزرق وقت التبريد، أحمر سريع إذا في تنبيه.
- **موجة ضو:** لما تشغّل ضو، بتطلع موجة بلونه من مكانه وبتعبي الشاشة.
- **كل صفحة إلها جو:** لون الخلفية حسب أيقونة الصفحة: الرئيسية ذهبي، الأمان أزرق، الكهربا أخضر.
- **قوس الشمس والقمر:** بالبار (على الشاشات العريضة)، مع وقت الشروق والغروب.
- **شعار العيلة:** اكتب "آل محمد"، وبيطلع ختم ذهبي بحروف العيلة بدل اللوجو.
- **أجواء الفصول:** ثلج بالشتا، ورد بالربيع، لمعة حر بالصيف، ورق شجر بالخريف. لحالها حسب التاريخ.
- **الخلفية بتتراجع:** لما تفتح نافذة، الداشبورد وراها بيصغر شوي وبيتغبّش، زي الآيفون.

## كيف بيشتغل

| الشي | التفاصيل |
|---|---|
| **الإعدادات** | محفوظة بـ `.storage/smartnest.dashboard`، وبتدخل بالـ backup |
| **صور المخطط** | `/config/smartnest/floorplans/`، بأسماء عشوائية (128-bit) |
| **الصلاحيات** | الكل بيقرأ، والأدمن بس بيحفظ وبيرفع (الفحص على السيرفر، مش بس بالواجهة) |
| **صور الزوار** | `/config/smartnest/visitors/`، بأسماء عشوائية، وبتنمسح لحالها بعد كم يوم |
| **الكاميرات** | صورة بتتحدّث كل 10 ثواني، وبث مباشر MJPEG لما تفتح الكاميرا. بيشتغل مع أي كاميرا بيعرفها HA |
| **الجرس** | entity من نوع `event.*` أو `binary_sensor.*`. لما يدق، بتطلع نافذة على كل الشاشات المفتوحة |
| **القفل** | ما بينفتح بضغطة وحدة أبدًا. لازم ضغطتين، والثانية لازم تكون خلال 4 ثواني |
| **قفل الشاشة (kiosk)** | زر 🔒 بالبار بيخبّي قائمة HA وبيمنع الخروج من الداشبورد إلا بالرمز. الرمز إلك، وبتحطه من الإعدادات. القفل لكل جهاز لحاله. **قفل للبيت (أولاد وضيوف)، مش حماية أمنية**: للقفل الكامل استعمل Fully Kiosk Browser أو Guided Access |
| **اللغات** | عربي، إنجليزي، عبري. RTL كامل، بس المخطط ما بينقلب |
| **الخطوط والأيقونات** | Rubik (فيه عربي وعبري) وMDI، من الـ Design System |

### لازم تعرفها
- **صور المخطط بتنفتح بدون تسجيل دخول** لأي حدا بيوصل لـ HA وبيعرف اسم الملف (الاسم عشوائي وما بينخمّن). هاد نفس سلوك `/local` بـ HA. ما في صور كاميرات هون.
- ملفات **SVG ممنوعة** بالرفع، لأنها ممكن تحمل سكربت.
- لما تغيّر صورة مخطط، القديمة بتضل على الديسك. (التنظيف بنسخة جاية.)
